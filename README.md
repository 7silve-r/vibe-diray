# Vibe Random Notes

音乐与日记一体化应用，共用账号、权限系统和全局播放器。

- `backend/diary`：账号、权限、日记及公开互动。
- `backend/music`：音乐业务与唯一后端启动程序。
- `frontend`：Vue 客户端、欢迎页、播放器与管理页面。
