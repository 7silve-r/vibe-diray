| 场景                                        | HTTP 状态 | 处理方式                                   |
| ------------------------------------------- | --------- | ------------------------------------------ |
| 参数缺失、类型错误、错误 JSON、业务校验失败 | 400       | 展示校验提示                               |
| 未登录、Token 失效、账号已删除              | 401       | 清除统一登录态；日记本机草稿保留   |
| 没有权限                                    | 403       | 提示没有权限，保留当前登录状态           |
| 资源不存在                                  | 404       | 提示内容不存在                             |
| 请求方法不支持                              | 405       | 保留 Allow 响应头                          |
| 数据重复或仍被引用                          | 409       | 提示数据冲突，不返回 SQL、索引或数据库内容 |
| 上传体过大 / 内容类型不支持                 | 413 / 415 | 提示调整上传内容                           |
| 数据库、MinIO 或邮件服务不可用          | 503       | 提示稍后重试；不会误报登录过期             |
| 文件读写或未预料到的服务端异常              | 500       | 用户看到安全提示，详细原因保留在后端日志   |
